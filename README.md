# Weather Data Analysis – Python & Pandas

Exploratory analysis of an hourly weather dataset covering 8,784 records across 8 variables including temperature, wind speed, visibility, humidity, and atmospheric pressure.

## What this project covers:
* **Unique value extraction** • **Conditional filtering** • **Multi-condition queries** • **GroupBy aggregations** • **Statistical measures** (mean, std dev, variance) • **String pattern matching** • **Null value auditing** • **Column renaming and data reshaping**

## Key findings:
* **Clear weather** was recorded 1,326 times across the dataset.
* **583 snow-related records** identified using pattern matching across condition types.
* **Zero null values** – dataset required no imputation.
* **Atmospheric pressure standard deviation:** 0.84 kPa.

**Tools:** Python • Pandas • Jupyter Notebook
**Skills demonstrated:** Data exploration, filtering logic, aggregation, statistical analysis, clean code documentation.
